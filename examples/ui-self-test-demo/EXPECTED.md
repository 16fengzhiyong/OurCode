# 期望行为清单（AI 自测对照表）

本文件是「任务管理工作台」的验收依据。AI 在完成 UI 自测时，逐条在真实浏览器中
**点击 / 输入 / 读取页面快照**进行验证，并给出 通过 / 失败 结论。

## 前置条件

- 静态服务已启动（如 `npx serve app` 或 `python -m http.server 8080 -d app`）；
  `@playwright/mcp` 默认屏蔽 `file://`，必须通过 http 访问页面。
- Playwright MCP 浏览器已就绪（`browser_navigate` 等工具可用）。

## 验证项

### 1. 页面加载
- [ ] `browser_navigate` 打开页面后，标题包含「任务管理工作台」。
- [ ] 顶部导航包含三个页签：仪表盘 / 任务列表 / 设置。

### 2. 仪表盘
- [ ] 默认展示「仪表盘」页签内容。
- [ ] 三个统计卡片（总任务 / 已完成 / 进行中）初始值均为 `0`。

### 3. 任务添加与校验
- [ ] 切到「任务列表」页签，空列表时显示「暂无任务」。
- [ ] **不输入任何内容**直接点「添加任务」→ 出现错误提示「任务描述不能为空」。
- [ ] 输入「完成季度报告」后点「添加任务」→ 错误提示消失，任务出现在列表中，
      计数变为「共 1 项 · 显示 1 项」。
- [ ] 继续添加至少一条中文、一条英文任务，列表与计数同步更新。

### 4. 完成 / 删除
- [ ] 勾选某任务的复选框 → 该任务文字出现删除线（completed 样式），
      仪表盘「已完成」+1、「进行中」-1。
- [ ] 点某任务的「✕」删除按钮 → 任务从列表消失，计数 -1。

### 5. 搜索过滤
- [ ] 在搜索框输入关键词（如「季度」）→ 列表只剩匹配项，计数显示「显示 N 项」。
- [ ] 清空搜索框 → 全部任务恢复显示。

### 6. 设置：用户名
- [ ] 切到「设置」页签，输入名字（如「李雷」）并失焦/回车保存。
- [ ] 回到「仪表盘」→ 问候语变为「你好，李雷！」。

### 7. 设置：主题
- [ ] 点「🌙 深色」→ 页面 `body` 的 `data-theme` 变为 `dark`，背景变暗。
- [ ] 刷新页面后主题仍为深色（localStorage 持久化）。

### 8. 稳定性
- [ ] 全程无页面崩溃、无未捕获 JS 报错（`browser_console_messages` 无 error 级别日志）。

## 输出要求

- 每项给出 通过 / 失败 / 跳过(原因)，失败项附 `browser_take_screenshot` 截图路径。
- 汇总：通过 X / 共 Y，剩余失败项及其根因分析。
