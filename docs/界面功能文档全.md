## 1. 主窗口与整体布局

- 无边框窗口（自绘标题栏），多窗口支持（新窗口）。
- 单实例运行：重复启动自动聚焦已有窗口。
- 分区：标题栏 / 活动栏 / 侧边栏 / 编辑区（可多分屏）/ 聊天面板 / 底部面板（问题、调试、终端）/ 状态栏。
- 侧边栏、聊天面板宽度可拖拽调整；聊天面板可切换右侧/底部/隐藏。
- 响应式：窗口 <1024px 紧凑布局，<768px 窄屏布局（聊天面板占整行）。
- 自动保存定时器（偏好设置可调间隔，实时生效）。
- 全局键盘快捷键分发（经统一命令注册表执行）。
- 拖拽文件时禁用标题栏窗口拖动区域，防止误触发窗口移动。
- 启动流程：加载配置 → 会话 → 偏好 → 主题 → 恢复上次项目 → 记忆/工作流/快捷键 → Git 分支 → 检查热退出备份 → 问题/LSP/Debug 订阅 → 首次运行显示 Onboarding。

## 2. 标题栏（TitleBar）

### 2.1 菜单栏（10 个菜单）

| 菜单 | 功能项 |
| --- | --- |
| 文件 | 新建文件（Ctrl+N）、打开文件夹（Ctrl+O）、保存（Ctrl+S）、全部保存（Ctrl+Shift+S）、新窗口、偏好设置 |
| 编辑 | 撤销（Ctrl+Z）、重做（Ctrl+Y）、剪切/复制/粘贴、查找（Ctrl+F）、替换（Ctrl+H）、命令面板（Ctrl+Shift+P） |
| 选择 | 全选（Ctrl+A）、展开选区（Shift+Alt+→）、收缩选区（Shift+Alt+←） |
| 查看 | 命令面板、切换侧边栏（Ctrl+B）、切换终端（Ctrl+J）、切换 AI 面板（Ctrl+L） |
| 转到 | 转到文件（Ctrl+P）、转到符号（Ctrl+Shift+O）、转到行（Ctrl+G）、转到定义（F12）、转到引用（Shift+F12） |
| 运行 | 调试类入口（当前禁用占位） |
| 智能体 | 新建对话、清空当前对话、导出对话为 Markdown、导出对话为 JSON |
| 终端 | 新建终端（Ctrl+`）、终端面板（Ctrl+J） |
| 扩展 | 扩展市场（Ctrl+Shift+X） |
| 帮助 | 报告问题（GitHub Issues）、功能请求、导出数据（JSON 备份，密钥打码）、清除数据（确认）、开发者工具 |

### 2.2 其他功能

- 菜单键盘导航：←/→ 切换菜单、↑/↓ 选项、Enter 激活、Esc 关闭。
- 命令中心（居中胶囊）：显示当前项目名；无项目时点击切换侧边栏；显示 AI 配置状态（绿色点=已配置）。
- 窗口控制：最小化、最大化/还原、关闭（关闭悬停红色）。
- 最大化状态监听（主进程事件推送）。

## 3. 活动栏（ActivityBar）

- 顶部图标：资源管理器（files）、源代码管理（git）、文件变更历史（changes）、Agent 任务（agent）、使用统计（usage）、扩展（extensions）。
- 底部图标：设置（打开设置弹窗）、账户（占位）。
- 行为：点击切换侧边栏对应 Tab；扩展直接打开插件市场弹窗；changes/agent/usage 自动展开侧边栏。
- 选中态：左侧 2px 强调条 + 高亮背景。

## 4. 侧边栏-项目列表（ProjectListPanel）

- 项目列表：最近打开项目 + 会话中出现的项目（按活跃时间排序），显示图标、名称、路径、打开时间（今天/昨天/N 天前）。
- 搜索框过滤项目（同时匹配项目名、路径、会话标题）。
- 点击项目进入该项目的文件树视图（含"返回项目列表"按钮）。
- 项目项 hover 显示"新建对话"按钮：为该项目创建新会话、切换工作区并打开聊天面板；无 API 配置时自动打开设置。
- 每个项目下列出其会话列表（最多 5 条，可展开剩余 N 条/收起），点击会话跳转聊天面板并激活。
- 会话状态点：运行中旋转指示、等待用户处理（待回答问题/待批准工具/待批准计划）显示气泡图标。
- 无项目绑定的"孤儿会话"分组单独显示在底部。
- 空状态："还没有打开项目" + "打开文件夹"按钮（系统文件夹选择）。
- 当前项目标记"当前"徽标。

## 5. 侧边栏-文件树（FileTree / FileTreeNode）

- 树形文件浏览：目录展开/折叠（懒加载子目录）、文件搜索过滤输入框（按文件名递归过滤并保留目录层级）。
- 点击文件在编辑器中打开；点击目录切换展开状态。
- Git 状态徽标：每 15 秒轮询 `git status --porcelain` 应用到树节点（M 修改/黄、A 新增/绿、D 删除/红、R 重命名/蓝、U 未跟踪/灰）。
- 文件系统 watch：目录变更自动重载树，保留已展开目录结构。
- 隐藏文件过滤（遵循设置项"显示隐藏文件"）。
- 文件图标按类型渲染。
- 文件节点右键菜单：打开、新建文件、新建文件夹、复制、剪切、粘贴、粘贴（移动）、重命名、删除（确认）、复制路径、在资源管理器中显示。
- 拖拽移动：文件/文件夹拖到目录上释放即移动（阻止拖到自身或自己的子目录）。
- 模块级剪贴板：跨树复制/剪切/粘贴文件。
- 树视图头部"新建对话"按钮。
- 初始加载 spinner。

## 6. 侧边栏-Git 面板（GitPanel）

### 6.1 变更管理

- 变更文件三分组：已暂存 / 未暂存 / 未跟踪，各带标题行。
- 单文件操作：暂存（+）、取消暂存（-）、添加跟踪（未跟踪文件）、查看差异、打开文件（点击文件名直接在编辑器打开）。
- 全局操作：全部暂存（`git add -A`）、取消全部暂存（`git reset HEAD`）、刷新状态。
- 状态图标：M 修改/黄、A 新增/绿、D 删除/红、R 重命名/蓝、U 未跟踪/灰。

### 6.2 Diff

- "查看变更 (diff)"：已有文件用 Monaco DiffView 展示 HEAD vs 工作区（带语言高亮）；新文件展示原始 git diff 文本。

### 6.3 提交

- 提交信息输入框（多行，Ctrl+Enter 提交）；提交 = 先 `git add -A` 再 `git commit -m`。
- **🤖 AI 生成提交消息**：基于暂存 diff 自动生成（temperature=0.3）；无模型配置时回退到 `git diff --cached --stat` 摘要行。
- **🛟 Lifeguard 预检**：对 `git diff HEAD` 运行 AI 提交前 Bug 检查，按错误/警告/建议分级展示问题数与列表（含修复建议）；无模型时提示配置。

### 6.4 同步与日志

- ↑ 推送（git push）、↓ 拉取（git pull 后刷新状态）。
- 📋 日志：拉取最近 20 条提交（hash/消息/作者/相对时间），可展开/关闭。

### 6.5 空状态

- 未打开项目 / 未检测到 Git 仓库 / 无更改 / 加载中 四种状态提示。

## 7. 侧边栏-文件变更历史（FileChangesPanel）

- 汇总所有会话中 AI 修改过的文件（来自 write_file / edit_file / delete_file / create_directory 工具调用），按会话分组、按时间倒序。
- 变更类型图标：A 新增/绿、M 修改/黄、D 删除/红。
- 点击文件行在编辑器打开。
- "查看变更"：弹窗 Monaco DiffView（原始内容取匹配 Checkpoint，当前内容读磁盘）。
- "↩ 回退"：确认后恢复该变更对应的 Checkpoint 快照并强制编辑器重载；找不到 Checkpoint 时提示。
- 变更预览弹窗内也提供"回退此变更"按钮。
- 空状态："暂无 AI 文件变更记录"引导。

---

## 8. 侧边栏-Agent 任务（AgentTasksPanel）

- "当前运行"区：列出所有进行中的 Agent 运行（支持并行会话），卡片显示状态徽标（运行中/创建计划/等待计划/已批准运行）、已耗时、任务描述、所属会话标题、工具调用数、文件变更数。
- "历史"区：最近 50 条已结束运行记录（按开始时间倒序）。
- 任务卡操作：打开会话（跳转聊天面板并激活）、停止（仅运行中显示）、删除记录。
- 每项目"始终允许"工具白名单管理器：显示 allowlist 工具名徽标 + "清空白名单"按钮。
- 空状态引导文案。

## 9. 侧边栏-使用统计（UsagePanel）

- 时间范围切换：7 天 / 30 天 / 90 天 / 全部。
- 数据变更事件（`ourcode:usage-recorded`）触发防抖自动刷新 + 手动刷新按钮。
- 清空统计数据（confirm 确认）。
- 四个统计卡片：请求总数、总 Token（含 ↑输入 / ↓输出）、今日 Token、失败请求数。
- Token 趋势图：SVG 堆叠柱状图（输入 + 输出）。
- 按模型排行（top 8：调用次数、token 总量、进度条）。
- 技能区：可用技能列表（名称、描述、调用次数、最后使用），每个带"运行"按钮（把"请执行技能「XX」"填入聊天输入框并打开聊天面板）；无本地文件的技能条目仅显示统计。
- 子代理使用排行（top 10：调用次数、错误计数）。
- MCP 使用统计：按服务器分组（连接健康度、工具调用数、错误计数），每服务器下列出各工具调用数。
- 最近活动流（最近 30 条，按类别着色，显示 token 或耗时与时间）。
- 空状态 / 加载中 / 错误提示。

## 10. 快速打开（QuickOpen）

- 触发：Ctrl+P / 菜单"转到文件"。
- 打开时递归遍历整个工作区收集文件（跳过隐藏文件）。
- 模糊匹配过滤（名称匹配优先于路径匹配，结果限 30 条）。
- 键盘导航：↑/↓ 选择、Enter 打开、Esc 关闭；鼠标点击/悬停。
- 文件列表显示类型标识（TS/JS/CSS/{}/MD/📄）与相对路径。
- 底部快捷键提示。

## 11. 编辑区-标签栏（TabBar）

- 显示/切换打开文件的标签页（点击切换活动文件），文件图标按类型渲染。
- 标签页拖拽排序（同面板内 reorder）。
- 跨面板拖拽移动标签页（从别的编辑器面板拖过来插入）。
- 关闭标签：未保存（dirty）文件弹确认"放弃修改并关闭"；dirty 文件显示黄色圆点，**点击圆点直接保存该文件**。
- 分屏按钮：左右分屏（水平分割）、上下分屏（垂直分割）。
- 关闭当前面板按钮（存在多个面板时显示）。
- 隐藏编辑器按钮（toggle 编辑区可见性，打开文件时自动恢复）。
- 空标签栏时显示拖拽提示文字，支持从外部拖入标签。

## 13. 编辑区-编辑器（EditorContainer）

### 13.1 基础编辑

- Monaco 编辑器初始化与生命周期管理（创建、销毁、多编辑器实例注册）。
- 按活动文件切换 Model，懒加载语言服务（TypeScript）。
- 语法高亮（60+ 语言）、行号、多光标、撤销/重做、查找/替换（Ctrl+F / Ctrl+H）。
- 光标位置追踪：跨标签页恢复每个文件的独立光标位置。
- 编辑自动标记 dirty；保存/回退/AI 上下文经 model registry 读取实时内容。
- 文件外部变更自动重载（watch 事件 + `ourcode:file-changed`，磁盘与编辑器不一致时回填）。
- 关闭文件时清理 LSP 连接与 Monaco 模型资源。
- 多面板支持：面板聚焦时设为活动面板。

### 13.2 大文件处理

- 大文件分块流式加载，进度百分比显示。
- **大文件优化模式**（>10MB）：关闭 minimap、折叠、悬浮提示、建议、括号着色等重特性，仅渲染核心文本。
- 超大文件只读预览；编码自动检测；保存保留原编码与 BOM。

### 13.3 AI 功能

- **行内补全（ghost text）**：AI 建议，Tab 接受。
- **右键菜单 AI 操作**（选中文本时）：解释代码、重构建议、✨ Vibe 替换（重写所选内容）、生成单元测试、生成文档注释、修复问题、优化性能、翻译为英文、触发 AI 内联补全、命令面板。
- AI 操作执行机制：无活动会话时自动创建会话并发送 prompt，随后打开聊天面板。
- **Vibe Replace**：把当前选中代码暂存为待替换内容，聚焦聊天输入框，AI 回复中的代码块可一键应用回编辑器选中区。
- 发送选中文本给 AI。

### 13.4 偏好同步

- 字体、字号、Tab 大小、minimap 开关、主题跟随设置实时更新。

### 13.5 空状态

- 欢迎卡片："打开文件夹 (Ctrl+O)" 和 "新建文件" 两个入口按钮。

## 24. 聊天面板-输入区（ChatInput）

- 自动增高文本域（≤200px），随会话运行状态切换占位符；无 API 配置时禁用。
- 发送按钮（无内容或未配置时禁用）；生成中变为"停止"按钮（仅停止当前会话，不影响并行会话）。
- Enter 发送、Shift+Enter 换行。
- **格式快捷键**：Ctrl+B / Ctrl+I / Ctrl+` 对选中文本应用粗体/斜体/行内代码标记。
- **@ 引用文件**：输入 @ 弹出文件名搜索结果（上下键 + Tab/Enter 选择、Esc 关闭、鼠标点击插入）；插入为 @路径 引用并加入上下文文件（chips 展示，点 × 移除并删除文本中对应 @引用）。
- **/ 斜杠命令**：行首 / 触发，支持过滤、上下键/Tab/Enter 选择；插入命令模板（含编辑器上下文），光标定位到插入后位置。
- **语音输入**：基于 Web Speech API，点击开始/停止听写（中文 zh-CN），识别结果追加到输入框；不支持时提示。
- 添加文件/附件按钮（系统文件选择对话框）。
- 拖放支持：从 OS 或文件树拖入文件——工作区内路径作为 @引用 + 上下文文件，工作区外路径作为纯文本插入并提示。
- Agent 运行中输入排队（type-ahead）：显示"已排队"提示，清空输入框。
- **Vibe 替换集成**：有待替换选区时，发送内容包装为 Vibe 替换指令。
- 监听 `ourcode:set-chat-input` 事件（技能面板注入技能指令到输入框）。

- "复制对比"：将所选模型对比文本复制到剪贴板（需 ≥2 模型）。

## 45. 通用组件

### ConfirmDialog
- 通用确认弹窗：标题 + 消息；取消 / 确认（打开时自动聚焦）；支持 danger/warning/info 三种主题样式；支持自定义按钮文案；Esc 取消、Enter 确认。

### ContextMenu
- 全局右键菜单：图标 + 标签 + 快捷键提示；支持分隔线、禁用项；点击执行后关闭；点击外部或 Esc 关闭；自动调整位置保持在视口内（边界 8px 防溢出）。

### NotificationToasts
- 分两栏：右上角（插件/信息类，5 秒自动消失）、右下角（会话事件类，8 秒，点击跳转）。
- 每条按类型（info/warning/error/success）显示左侧彩色边框；独立自动消失定时器；手动关闭（×）。
- 右下角 toast"查看"提示：点击跳转对应会话（已删除忽略；聊天面板未打开自动打开）。

### SessionEventNotifier（无 UI）
- 后台会话任务完成事件：会话离开运行态时经 1.2 秒防抖，用户不在该会话且计划未暂停时弹右下角 toast（成功/错误/信息，按运行状态与最后消息错误判定）。
- 后台会话需要输入事件：新的待提问/工具批准/批量批准/计划待批且用户不在该会话时弹警告 toast。
- 窗口未聚焦时同时触发系统通知；用户在浏览该会话时不上报。

### MarkdownRenderer
- Markdown 渲染（GFM、换行支持），DOMPurify 消毒防 XSS；代码块高亮（highlight.js）+ 语言标签 + 复制按钮（事件委托，CSP 兼容）；解析失败降级纯文本；语言切换时重新渲染。

### ErrorBoundary
- 渲染异常兜底：友好错误页 + 重试。

### LoadingSpinner
- 通用加载指示器。
