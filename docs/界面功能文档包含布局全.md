## 1. 主窗口整体布局

### 布局

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 标题栏 TitleBar（自绘无边框：Logo+菜单栏 ─── 命令中心 ─── 窗口控制按钮）    │
├────┬─────────────────────────────────────────────────────────┬─────────────┤
│ 活 │ 侧边栏 Sidebar（可折叠/拖宽 150~500px）                   │  聊天面板    │
│ 动 │  Tab 内容区：                                            │  ChatPanel   │
│ 栏 │  项目列表/文件树/Git/变更历史/Agent任务/用量              │（可折叠/拖宽 │
│(44)├─────────────────────────────────────────────────────────┤  250px~75%   │
│ px │ 编辑区（可多分屏）                                       │  窗口宽）    │
│    │  TabBar → BreadcrumbBar → Monaco 编辑器 / DiffView      │              │
│    ├─────────────────────────────────────────────────────────┤              │
│    │ 底部面板（可折叠）：问题 Problems / 调试 Debug / 终端 Terminal          │
├────┴─────────────────────────────────────────────────────────┴─────────────┤
│ 状态栏 StatusBar（左：Git分支/错误/警告 —— 右：更新/光标/编码/配置组/模型/…）│
└────────────────────────────────────────────────────────────────────────────┘
```

### 布局参数

- 窗口 1400×900，最小 800×600，无边框。
- 活动栏固定 44px；侧边栏 150~500px；聊天面板 250px ~ min(1100, 75% 窗口宽)。
- 终端面板高度 100~600px 可拖；问题面板 160px；调试面板 200px。
- 响应式：<1024px 紧凑（侧边栏收窄至 ≤200px）；<768px 窄屏（聊天面板占满整行、编辑区隐藏时聊天占满）。
- 聊天面板位置：右侧（默认）/ 底部（设置切换）。

### 全局功能

- 多窗口、单实例（重复启动聚焦已有窗口）。
- 全局快捷键分发（经统一命令注册表）；自动保存定时器。
- 拖拽文件时禁用标题栏拖动区（防窗口误移动）。
- 启动：恢复上次项目 → 加载记忆/工作流/快捷键 → 检查热退出备份 → 首次运行弹 Onboarding。

## 2. 标题栏（TitleBar）

### 布局

```
[●OurCode] [文件 编辑 选择 查看 转到 运行 智能体 终端 扩展 帮助]  [🔍 项目名 ●AI]  [— □ ✕]
```

左：Logo + 菜单栏；中：命令中心胶囊；右：窗口控制按钮。

### 功能

- 菜单栏 10 组（文件/编辑/选择/查看/转到/运行/智能体/终端/扩展/帮助），键盘导航（←/→ 切菜单、↑/↓ 选项、Enter、Esc）。
- 命令中心：显示项目名（点击切换侧边栏）或"打开文件夹"；AI 配置状态绿点；无配置显示"未配置"。
- 窗口控制：最小化 / 最大化-还原 / 关闭（悬停红色）。
- 菜单关键动作：新建文件、打开文件夹、保存/全部保存、新窗口、查找/替换、命令面板、切换侧边栏/终端/AI 面板、快速打开/符号/行/定义/引用、新建对话、清空对话、导出对话 MD/JSON、扩展市场、报告问题、导出数据、清除数据、开发者工具。

## 5. 侧边栏-项目列表（ProjectListPanel）

### 布局

```
┌ 项目列表 ─────────────────┐
│ [🔍 搜索项目]              │
│ ┌ 项目卡片 ────────────┐  │
│ │ 图标 名称     [新建对话] │  │
│ │ 路径 · 打开时间 · 当前 │  │
│ │  ┌ 会话1 (运行中●)   │  │
│ │  └ 会话2 …            │  │
│ └──────────────────────┘  │
│ 项目2 …                    │
│ 孤儿会话（无项目）         │
└───────────────────────────┘
```

### 功能

- 项目列表（最近打开 + 会话来源，按活跃时间排序），搜索过滤（名/路径/会话标题）。
- 点击项目进入文件树视图（返回按钮）；hover 显示"新建对话"（绑定项目、无配置自动开设置）。
- 项目下会话列表（≤5 条，可展开），点击激活；会话状态点（运行旋转/待输入气泡）。
- 孤儿会话分组；空状态"打开文件夹"引导；当前项目"当前"徽标。

## 6. 侧边栏-文件树（FileTree）

### 布局

```
┌ 项目名 ──────────────────┐
│ [🔍 搜索文件...]          │
│ ┌ 展开箭头 + 目录 + Git徽章
```

### 功能

- 右键菜单：新建文件/文件夹、复制、剪切、粘贴（移动）、重命名、删除、复制路径、在资源管理器中显示。
- 拖拽移动文件（防拖入自身子目录）；跨树剪贴板。
- 头部"新建对话"按钮。

## 7. 侧边栏-Git 面板（GitPanel）

### 布局

```
┌ 代码管理 ───────────────┐
│ [分支名]          [刷新] │
│ 提交消息 textarea        │
│ [🤖AI生成][🛟Lifeguard]   │
│ [提交] [↑推送] [↓拉取] [📋日志]
│ ─────────────────────   │
│ 已暂存（+/- 全部暂存）    │
│ 未暂存（+/- 全部暂存）    │
│ 未跟踪                   │
└─────────────────────────┘
```

### 功能

- 变更三分组（已暂存/未暂存/未跟踪），单文件暂存/取消暂存/打开/查看差异，全部暂存/取消。
- Diff：Monaco 对比 HEAD vs 工作区（新文件显示原始 diff 文本）。
- 提交：多行输入（Ctrl+Enter）；提交 = add -A + commit；AI 生成提交消息（无模型回退 stat 摘要）；🛟 Lifeguard 预检（错误/警告/建议分级 + 建议）。
- 推送 / 拉取 / 日志（最近 20 条，可折叠）。
- 状态图标 M/A/D/R/U；空状态（无项目/无仓库/无更改/加载中）。

## 14. 编辑区-编辑器（EditorContainer）

### 布局

```
┌─────────────────────────────────────────┐
│ 欢迎卡片（未打开文件时）                  │
│   [打开文件夹 Ctrl+O] [新建文件]        │
│ ─────────────────────────────────────── │
│ Monaco 编辑器（行号/高亮/minimap/…）     │
│ 大文件：顶部加载进度条 / 纯文本模式提示    │
└─────────────────────────────────────────┘
```

### 功能

- 多标签切换、多编辑器实例、光标位置跨标签恢复。
- 语法高亮（60+ 语言）、多光标、查找/替换、折叠、智能选区。
- 大文件流式加载 + 进度；>10MB 优化模式（关 minimap/建议/括号着色等）；只读预览。
- 外部变更自动重载；关闭清理 LSP/模型资源。
- 右键 AI 操作：解释、重构、Vibe 替换（✨ 重写选区→聊天回复可一键应用回编辑器）、单测、文档、修复、优化、翻译、内联补全。
- 行内补全 ghost text（Tab 接受）；AI 操作自动建会话并开聊天面板。
- 偏好实时同步（字体/字号/Tab/minimap/主题）；欢迎卡片。
