> 日期：2026-08-10
> 状态：评审中

## 1. 文档说明

本文档按**界面区域**逐区描述 OurCode IDE 的界面构成与交互功能，是 UI 开发、测试用例编写与用户手册的基础。每个界面元素标注其关键行为；与需求/设计文档的映射见 §11。

## 2. 界面总体布局

```
┌────────────────────────────────────────────────────────────────────────┐
│ TitleBar 标题栏（无边框窗口：Logo + 菜单栏 + 命令中心 + 窗口控制）      │
├────┬───────────────────────────────────────────────────┬──────────────┤
│ 活 │ 侧边栏 Sidebar（可折叠、可拖宽 150~500px）          │  聊 天 面 板  │
│ 动 ├───────────────────────────────────────────────────┤  ChatPanel    │
│ 栏 │ 编辑区（可多分屏）                                  │（可折叠、可拖宽│
│    │  TabBar → BreadcrumbBar → Monaco 编辑器 / Diff     │  250px~75%窗  │
│    │ ──────────────────────────────────────────────────┤  │
│    │ 底部面板：Problems / Debug / Terminal（可折叠）    │  │
├────┴───────────────────────────────────────────────────┴──────────────┤
│ StatusBar 状态栏（Git 分支 / 错误警告数 / 光标位置 / 编码 / 配置组 /    │
│ 模型 / tokens / 版本 / 更新状态）                                      │
└────────────────────────────────────────────────────────────────────────┘
```

### 2.1 布局参数

| 区域 | 参数 | 说明 |
| --- | --- | --- |
| 主窗口 | 1400×900，最小 800×600，无边框（frame:false） | 深色底 #1e1e1e |
| 活动栏 | 固定 44px 宽 | 顶部 6 图标 + 底部 2 图标 |
| 侧边栏 | 150~500px 可拖拽（窄窗 ≤200px） | `resizer` 手柄 |
| 聊天面板 | 250px ~ min(1100, 75%窗口) 可拖拽 | 可切换右侧/下方/隐藏 |
| 终端 | 高度 ≤500px（窄窗 ≤180px） | 底部折叠面板 |
| 响应式断点 | 1024px 紧凑 / 768px 窄屏 | 窄屏下聊天面板占满整行 |

### 2.2 主题与样式

- 深色 / 浅色 / 跟随系统三种主题；自定义强调色。
- 样式通过 CSS 变量驱动：`--bg-tabs`、`--border`、`--accent`、`--surface` 等。
- 毛玻璃面板 `glass-panel`、品牌渐变 `--grad-brand`、脉冲 Logo 动效。

### 3.2 功能明细

## 5. 侧边栏（Sidebar）

### 5.1 通用结构

- 顶部：图标 + 标题（项目列表 / 代码管理 / 文件变更历史 / Agent 任务 / 使用统计）+ 操作按钮（新建对话、刷新、折叠）。
- 可拖拽宽度（150~500px），窄窗自动收窄到 200px。

### 5.2 项目列表 / 文件树（files）

- **项目列表视图**（默认）：多项目卡片列表，每个项目项可**新建对话**（按项目打开会话）。
- **树视图**：文件树（FileTree），显示 Git 状态徽标（M/A/D/R），右键菜单、拖放移动文件。
- 工具栏按钮：新建对话（+）、切换列表/树视图。
- 头部支持"打开文件夹"（Ctrl+O）。

### 5.3 代码管理（git / GitPanel）

| 功能 | 说明 |
| --- | --- |
| 状态列表 | 变更文件分组（暂存/未暂存），点击展开 Diff |
| Diff 视图 | 行级增删对比 |
| 暂存/取消暂存 | 单文件或全部 |
| 提交 | 提交信息输入 + **AI 生成提交信息** + **Lifeguard 提交前预检** |
| 同步 | Push / Pull |
| 日志 | 提交历史查看 |

### 5.4 文件变更历史（changes / FileChangesPanel）

- 展示工作区文件变更记录（基于 Git 状态）。
- 头部"刷新"按钮（重新加载应用）。

### 5.5 Agent 任务（agent / AgentTasksPanel）

| 区域 | 内容 |
| --- | --- |
| 当前运行 | 正在运行的 Agent run（任务、状态、耗时、工具调用数、文件改动数、停止按钮） |
| 历史任务 | 已完成/失败/停止的记录，可打开会话、删除记录 |
| 工具白名单 | 本项目已允许的工具列表（始终允许清单），可清空 |

### 5.6 使用统计（usage / UsagePanel）

| 区域 | 内容 |
| --- | --- |
| 时间范围 | 7天 / 30天 / 90天 / 全部 切换 |
| 总览卡 | 总请求、总 Token、今日 Token、失败数、输入/输出 Token |
| Token 趋势图 | 按日折线 |
| 排行 | 按模型 / 技能 / 子智能体 / MCP 工具 排行（次数、tokens、错误、最近使用） |
| 最近活动 | 事件列表（分类/名称/时间/tokens/成败） |
| 操作 | 刷新、清空数据（确认框）、运行技能（从技能列表直接触发） |

## 6. 编辑区

### 6.1 多标签（TabBar）

- 每个分屏面板独立 TabBar（panelId 区分）。
- 标签：文件名 + 脏状态圆点 + 关闭按钮；右键菜单；拖拽排序。
- 快捷键：关闭标签 Ctrl+W、切换文件等。

### 6.2 面包屑（BreadcrumbBar）

- 显示当前文件路径层级，可点击导航；文件符号下拉。

### 6.3 代码编辑器（Monaco）

| 功能 | 说明 |
| --- | --- |
| 编辑 | 多标签编辑、撤销/重做、查找/替换（Ctrl+F / Ctrl+H） |
| 智能感知 | 语法高亮（60+ 语言）、代码补全、Snippet |
| 行内 AI 补全 | ghost text，Tab 接受 |
| 导航 | 转到定义（F12）、转到引用（Shift+F12）、符号大纲、跳转行 |
| 大文件 | 分块流式加载 + 进度条；超大文件降级纯文本/只读 |
| 编码 | 打开自动检测；保存保留原编码与 BOM（状态栏可切换编码） |

### 6.4 Diff 视图（DiffView）

- 文件对比 / Git 变更 Diff，行级着色。

### 6.5 分屏

- `Ctrl+\` 水平分屏，`Ctrl+Shift+\` 循环焦点，面板分割线拖拽调整比例（15%~85%）。

### 6.6 问题面板（ProblemsPanel，Ctrl+Shift+M 或状态栏点击）

- 展示 LSP 诊断 / Monaco 标记：错误、警告、信息，按文件分组，点击跳转。
- 固定在编辑区底部（高 160px），可折叠。

### 6.7 调试面板（DebugPanel）

| 控件 | 功能 |
| --- | --- |
| 适配器命令 | 调试适配器命令（如 `node mock-adapter.js`）+ 启动参数 |
| ▶ 启动 / 暂停 / 继续 / 单步跳过 / 单步进入 / 单步跳出 / 停止 | DAP 会话控制 |
| ⛶ 断点 | 在光标处添加断点；断点列表管理（移除、清除全部） |
| 输出 | stdout/stderr 实时输出，可清空 |
| 状态 | 停在文件行提示 |

## 7. 聊天面板（ChatPanel）

### 7.1 面板布局

```
┌─ 头部：Logo+OurCode AI+连接状态+会话标题(可改名) ─ 历史/模型选择/⋮菜单 ─┐
├─ 消息区 ChatMessages（流式消息、思考块、工具调用块、Agent 执行流）     │
├─ 模式栏：💬对话 | 🤖Agent ── (目标模式胶囊) (编辑方式下拉) ──────────────┤
├─ 输入区 ChatInput（多行、@引用、/命令、语音、附件、发送/停止、排队提示）│
└─ 提问确认条 QuestionConfirmBar（AI 需要确认时）────────────────────────┘
```

### 7.2 头部

| 元素 | 功能 |
| --- | --- |
| 品牌 | WaveLogo + "OurCode AI" + 连接状态胶囊（已连接绿点 / 未配置灰点→点击去设置） |
| 会话标题 | 行内编辑改名（点击→输入框，Enter 提交，Esc 取消，切换会话自动放弃草稿） |
| 🕐 历史 | 打开会话列表（ChatSidebar） |
| 模型选择 | 胶囊按钮 → 弹出 ModelSelector（分组/模型列表、收藏、免费标记） |
| ⋮ 更多 | Arena 模型对比、工作流、记忆管理、设置 |

### 7.3 会话列表（ChatSidebar）

| 功能 | 说明 |
| --- | --- |
| 会话列表 | 按项目分组；搜索会话（关键词过滤）；未关联项目会话独立分组 |
| 会话操作 | 置顶、归档/取消归档、隐藏/显示归档、删除（确认框）、重命名 |
| 导入/导出 | 导出 Markdown / JSON、导入对话（JSON） |
| 历史编辑 | 打开"对话历史"编辑器（可编辑/重跑） |
| 新建对话 | 创建新会话 |

### 7.4 消息区（ChatMessages）

| 元素 | 功能 |
| --- | --- |
| 消息气泡 | 用户 / AI / 工具 三种角色区分；显示 token 数、时间 |
| 思考块 | 可折叠"思考过程" |
| 工具调用块 | 工具名 + 参数预览 + 结果；成功/失败/被拒绝状态图标 |
| Agent 执行流 | AgentRunPanel：执行轨迹时间线、总步骤数、子 Agent 运行状态 |
| 消息操作 | 编辑、重新生成、分支（从此消息创建）、回滚修改（↩ 回滚该消息的文件改动）、记住（🧠 浓缩到记忆）、复制代码块、⤓ 应用到编辑器 |
| 代码块 | 语法高亮 + 复制 + 应用到编辑器（选区替换，成功打 ✓） |
| 错误卡片 | 结构化错误（认证/超时/网络/限流/服务器），含"前往设置""重试""查看详情" |
| 删除反馈 | 已删除 N 条消息 + 撤销按钮 |
| 上下文警告 | token 用量接近窗口上限时黄条提示 |
| 继续执行 | 工具轮数用尽后消息尾部"继续执行"按钮 |

### 7.5 模式栏

| 控件 | 功能 |
| --- | --- |
| 💬 对话 / 🤖 Agent | 切换会话模式；Agent 需先打开项目（否则提示"需要先打开项目文件夹"） |
| 目标模式胶囊 | 实验性目标模式开关：开启后 Agent 自主运行（自动批准+自动继续），绿色脉冲；显示当前实现状态徽标（5 秒轮询）；开启前提示 token 用量风险；同一项目互斥 |
| 编辑方式下拉 | 手动确认 / 自动编辑 / 计划模式 / 完全访问（目标模式运行时仅保留 手动确认/完全访问） |

### 7.6 输入区（ChatInput）

| 功能 | 说明 |
| --- | --- |
| 多行输入 | 自动增高（≤200px）；Enter 发送、Shift+Enter 换行；`/` 触发斜杠命令、@ 引用文件（项目内作为上下文，外部文件降级为纯文本） |
| 上下文文件 | 引用文件以标签 chips 展示，可移除 |
| 语音输入 | 语音识别按钮（环境不支持时提示） |
| 生成中状态 | 停止按钮；排队横幅（生成中可排队多条消息） |

| 弹窗 | 功能 |

| HistoryEditor | 编辑对话历史（修改、删除、重跑任意消息） |

### 10.1 设置弹窗（SettingsModal）

**Tab 1：API 配置**
- 配置组列表：当前使用徽标、密钥掩码、颜色标签、"使用/测试/编辑"操作、模型列表（自动拉取）。
- 配置组编辑器：名称、提供商（8 类）、Base URL、API Key（支持环境变量）、默认模型、系统提示词（模板插入 + 字符/token 计数 + 导入/导出 + 历史恢复）、颜色标签、自定义请求头（JSON）、跳过证书校验、传输格式覆盖。
- 模板库：通用助手 / Python 专家 / 代码审查 / 前端专家 / API 设计 / 文档撰写 / Bug 修复 / SQL 专家。
- 导出/导入配置（可选加密口令）。

**Tab 2：偏好设置**
- 外观：主题（深/浅/跟随系统）、语言（系统/简体中文/English）、主题色（预设+自定义）。
- 编辑器：字体大小、制表符大小（空格数）、迷你地图、自动保存（间隔）。
- 文件资源管理器：显示隐藏文件。
- AI：聊天历史编辑模式、允许 AI 自动记忆、LLM 响应缓存、Anthropic 提示缓存、跨会话消息策略（接受/挂起/拒绝）。
- LSP：每行 `language:command` 配置。
- 聊天：面板位置（右侧/底部）。
- 危险区域：重置所有设置（两级确认）。

**Tab 3：快捷键**
- 预设：VS Code / JetBrains / 自定义。
- 分类查看（文件/编辑/视图/对话/AI），支持自定义绑定、新增快捷键、重置。

## 12. 交互细节

### 12.1 拖拽与调整
- 侧边栏 / 聊天面板宽度拖拽（`resizer` 手柄，拖拽中禁用文本选择）。
- 分屏比例拖拽（15%~85% 限制）。
- 拖拽文件到文件树移动；拖拽消息排序（历史编辑模式）。
- HTML5 拖拽进行中禁用标题栏 -webkit-app-region，防止误触发窗口移动。

### 12.2 反馈机制
- 长耗操作：流式输出 / 加载进度条 / Agent 运行轨迹 / 通知 toast。
- 错误：结构化错误卡片（可折叠详情）+ 状态栏更新徽标。
- 危险操作：确认框（清数据、删会话、重置）多级确认。

### 12.3 会话级提示
- token 用量接近上限：输入区上方黄条提醒。
- 生成中排队：横幅显示队列数量。
- Agent 需要确认：提问确认门槛（立即处理 / 稍后）。
