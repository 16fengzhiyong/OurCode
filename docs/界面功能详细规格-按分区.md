## S1 主窗口框架与全局外壳

### 布局结构

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ TitleBar（悬浮玻璃条）：Logo+品牌 ─ 菜单胶囊(文件/编辑/…) ─ 命令中心 ─ 窗口控制 │
├─┬───────────────┬───────────────────────────────────────────────┬───────────┤
│活│ Sidebar       │ Editor 区（悬浮玻璃面板）                       │ ChatPanel │
│动│ (玻璃面板)     │  TabBar → Breadcrumb → Monaco(深色代码区)      │ (玻璃面板) │
│栏│               ├───────────────────────────────────────────────┤            │
│  │               │ 底部面板：Problems / Debug / Terminal(深色)    │            │
├─┴───────────────┴───────────────────────────────────────────────┴───────────┤
│ StatusBar（悬浮玻璃条）：左 Git分支/错误/警告 ── 右 编码/行尾/缩进/模型/版本   │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 控件明细与五要素

#### 1.1 主窗口
- **布局**：无边框窗口，整窗由 TitleBar / ActivityBar / Sidebar / Editor 区 / 底部面板 / ChatPanel / StatusBar 七个悬浮玻璃分区组成，分区之间留 4–8px 间隙，画布底色 `#f6f7fb` 且带两团柔和果味渐变光晕（蓝→紫 / 橙→桃红）。
- **触发**：应用启动（单实例，重复启动聚焦已有窗口）。
- **交互流程**：启动加载 配置→会话→偏好→主题→恢复上次项目→记忆/工作流/快捷键→Git 分支→检查热退出备份→问题/LSP/Debug 订阅→首次运行显示 Onboarding。
- **状态**：加载中（全局 spinner）/ 就绪 / 错误（ErrorBoundary 兜底页）。
- **边界**：窗口 <1024px 紧凑布局（侧边栏收窄），<768px 窄屏布局（聊天面板占整行）；侧边栏/聊天面板宽度可拖拽（侧边栏 150–500px，聊天 250px–75% 窗宽）；自动保存定时器可调。
- **数据**：uiStore（sidebarWidth/chatWidth/chatPosition）、editorStore（panelOrder/splitDirection/splitRatios）、preferencesStore。
